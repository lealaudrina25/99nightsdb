Almost every failed code is one of eight problems, and six of them take seconds to fix. Work down this list in order — it is sorted by how often each one is the actual cause.

Last verified: **2026-09-29**.

## 1. You Are Not in the Lobby

**The most common cause by a distance.** The Codes button only exists in the **main lobby**. If you have already started a run, there is nothing to click.

Fix: finish or leave the run, return to the lobby, and open the Currency Shop again.

One subclass of that failure is specific to fishing: the code will not fire unless you are already holding a rod and mid-cast. [**Fishing in 99 Nights in the Forest**](/guides/fishing-guide) gives the exact sequence.

## 2. It Is a Chat Code

`yay fishing` is a hidden in-run activation, **not** a shop code. Typing it into the Codes box will fail every single time, forever.

It works like this instead: campfire at **Level 2**, Old Rod from the Fishing Shack, start the fishing minigame, press **`/`**, type `yay fishing`, Enter. Rewards fall from the sky.

## 3. A Space or a Capital Letter

Codes are **case-sensitive** per most sources and most player reports. One tracker disagrees, but the safe move is to **copy and paste** rather than type — that settles the argument and removes trailing spaces at the same time.

A space at the end of a pasted code is the sneaky version of this failure: everything looks right and it still rejects.

## 4. You Already Used It

Every code is **one-time per account**. If the game says already redeemed, that is not a bug — it has been claimed on your account before, possibly by you weeks ago.

There is no way to reset this and no reason to try again.

## 5. It Expired

Codes are tied to updates and seasonal events, and they die when the window closes. A Halloween code stops working the day Halloween content is pulled, permanently.

This is also why a code you saw on a video three months ago no longer works. It was probably real when it was posted.

## 6. Your Server Is Stale

When a code is brand new, it does not reach every server at once. Trackers show this clearly: a freshly added code often reports a low success rate for the first day or two, then climbs.

Fix: **leave and rejoin** the game, then submit again. Do this before concluding anything else.

## 7. It Is a Merch Code

Codes from physical merchandise are redeemed through a **different path**: open the Buy Diamonds window, click Codes, and **tick the "Merch" box** in the pop-up before submitting.

Without that checkbox ticked, a perfectly valid merch code will look broken. Separately, if you redeemed through the web portal, **you must enter the game within 24 hours** or the code expires and has to be re-entered.

## 8. The Code Was Never Real

This is the one people least expect, and the one that wastes the most time.

- **Generator sites do not work.** There is no working code generator for this game. Any site asking you to log in, complete a task or watch an ad to unlock a code is farming you.
- **Fabricated expired-code lists.** Several sites publish long tables of dead codes with impossible dates — codes that supposedly expired before the game launched in March 2025, or that paid out thousands of Diamonds. Those tables are invented. A code list you cannot date is not a code list.

Verify against the official **Grandma's Favourite Games Discord** or the developer's Roblox group before you believe a code exists.

## Still Not Working?

In order:

1. **Rejoin the game** and try once more in the lobby.
2. **Restart Roblox** entirely if you have had the client open for hours.
3. **Check whether the code is still listed as working** on [Active Codes](/codes/active-codes).
4. **If it is listed as working and still fails, tell us.** That is the signal that a code has quietly died, and it is exactly the kind of thing this page exists to correct.

Do not submit the same code dozens of times. There is no lockout, but there is also no benefit.

## Quick Reference

| Symptom | Most likely cause |
|---|---|
| No Codes button at all | You are mid-run, not in the lobby |
| "Invalid code" | Typo, extra space, or the code is fake |
| "Already redeemed" | One-time per account, already claimed |
| New code rejected on day one | Server has not received it yet — rejoin |
| Merch code rejected | "Merch" checkbox not ticked |
| Chat code rejected in the shop | `yay fishing` never works in the box |
| Worked last week, dead now | Update or event window closed |
