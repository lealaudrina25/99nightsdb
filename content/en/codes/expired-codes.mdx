The reality in 99 Nights in the Forest is the opposite: the developers release codes rarely, and almost none of them ever get switched off. This page keeps the genuinely dead ones and flags the rest as unverified.

## Why So Few Codes Expire

Unlike games that rotate a fresh promo every week, 99 Nights in the Forest treats codes as rare, roughly one-off drops tied to updates or seasonal events. Two consequences:

- **The active codes almost never get pulled.** The launch-era codes have stayed live for over a year.
- **A long "expired" list is usually a red flag.** If a page shows twenty dead codes, most of those strings probably never redeemed in the first place.

So before you trust any "expired" entry, check whether a *reputable* tracker (not a Robux-selling blog) confirms it. The live, working list is on [Active Codes](/codes/active-codes).

## Why Codes Expire (and Never Come Back)

When a code is pulled, the developers disable it **server-side**. There is no client trick, no alt account, and no "reactivation date." The usual reasons:

- **The event ended.** Seasonal codes (like `happyhalloween`) die with the event.
- **The promo window closed.** Launch or milestone codes get switched off after a set period.
- **It was a bug-compensation code.** One-off payouts for a broken update, removed once the fix shipped.

If a code fails today, the practical move is the same either way: stop retyping it and grab the current working set from [Active Codes](/codes/active-codes).

## Don't Trust "Code Generator" Sites

No website can generate working codes, and no code ever grants Robux, pets, or weapons. Anyone promising those is running a scam or an affiliate link. Real codes come from the developer's Discord and in-game loading screens, then get mirrored on reputable trackers.

## FAQ

**Is `happyhalloween` ever coming back?**
Only if the Halloween event itself returns. The code is tied to that event, not a calendar date, so don't hold your breath.

**Are there codes that give Robux or pets?**
No. Codes only hand out Diamonds, Gems, Flames, or event items like Candy. Anything else is a lie.
