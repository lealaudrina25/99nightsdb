## What Codes Give You

Codes are released by the developers around updates and seasonal events. They do not give you weapons, pets or Robux — anyone promising that is lying. What they give is currency:

- **Diamonds** — the main currency, spent on permanently unlocking classes.
- **Flames** — spent at the supply crate to change which events run during a night.

**Diamonds and Gems are the same currency.** You will see both names, and several guides insist Gems are a separate, weaker currency — but every price and payout lines up exactly once you assume they are one balance. The class screen tends to say Gems; code rewards and chests say Diamonds. See [How to Get Diamonds Fast](/items/how-to-get-diamonds-fast) for the full comparison.

Because class unlocks are permanent and Diamonds are saved to your Roblox account rather than to a run, codes are the fastest free route to a better class. Save toward **one** class that fits how you play rather than half-buying two.

## How to Redeem Codes

The redeem box is inside the shop, not in its own menu, which is why so many players cannot find it. **You must be in the main lobby — codes cannot be redeemed once a run has started.**

1. Launch the game and **stay in the lobby**. Do not start a run.
2. Open the **Currency Shop**: click the Gems or Diamond button, or the diamonds icon at the bottom-left of the screen.
3. Click the **Codes** button in the **bottom-right** of that window.
4. Type or paste the code exactly as written, with no extra spaces.
5. Press **Submit**. The reward lands instantly.

There is **no level requirement** to redeem.

Codes are **case-sensitive** — one tracker claims otherwise, but the majority of sources and most player reports say capitalisation matters. Copy and paste rather than typing by hand and you sidestep the argument entirely.

The prerequisite for that one is simply having a rod in hand, which every class can arrange but one gets for free from the first minute. See [**Fisherman Class**](/classes/fisherman-class).

One step further out: everything tier 5 asks for beyond this also wants the **Gem of the Forest**. The spend plan that spreads it across the tier-5 machines is on the [Gem of the Forest](/items/gem-of-the-forest) page.

## The Chat-Only Code

`yay fishing` **does not work in the shop box.** It is a hidden in-run activation:

1. Start a session and upgrade the campfire to **Level 2**.
2. Get the **Old Rod** from the Fishing Shack.
3. Begin the fishing minigame.
4. Press **`/`** to open chat, type `yay fishing`, and press Enter.

Rewards fall from the sky. It is one-time per account. You will see the payout written as either 2 Diamonds or 2 Gems — they are the same currency, so both are right.

## One Code We Cannot Call

**`SURVIVOR`** is listed as **active** by one major tracker (added August 2026, with mixed community success reports) and as **expired** by others, including an earlier version of this page.

We are not going to pretend to know. **Type it and see.** It costs you five seconds, and if it fails, it is expired.

## Merch Codes Need a Different Box

If you bought physical 99 Nights merchandise, its DLC code is **not** redeemed the normal way. Per the official redemption instructions:

- Open the **Buy Diamonds** window, click **Codes** in the bottom-right.
- In the pop-up, **tick the "Merch" box** before submitting.
- Codes can also be redeemed through the official web portal — but **you must enter the game within 24 hours** of doing so, or the code expires and has to be re-entered.

Missing the Merch checkbox is the single most common reason a legitimate merch code appears to fail.

## Where New Codes Appear

Codes drop alongside **major content updates and seasonal events**, not on a weekly schedule. The fastest sources are the **Grandma's Favourite Games Discord** and the developer's Roblox group announcements.

Since the game ships headline updates roughly every two weeks on a Saturday, that is when to look. See [Update Log & Patch Notes](/guides/updates-patch-notes) for the schedule.

## Common Mistakes

- **Redeeming mid-run.** The box is lobby-only.
- **Pasting a chat code into the shop.** `yay fishing` will never work there.
- **Trusting generator sites.** There is no working generator for this game. If a site asks you to log in or complete a task to unlock a code, leave.
- **Waiting to redeem.** Codes vanish between reading them and logging in.

If a code refuses to work and none of the above explains it, see [Codes Not Working](/codes/codes-not-working) for the full checklist.
