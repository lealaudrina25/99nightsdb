A code fails far more often because it went into the **wrong box** than because it is dead. 99 Nights in the Forest does not have one redeem screen — it has **four different redemption paths**, and they are not interchangeable. This page is the map: which path your code needs, and the exact steps for each. For the codes that currently work, see [Active Codes](/codes/active-codes); if a code still fails on the right path, the full checklist is on [Codes Not Working](/codes/codes-not-working).

Last verified: **2026-09-30**.

## Which Path Does My Code Need?

| Your code | Path | Where |
|---|---|---|
| A normal reward code (`afterparty`, `forestwakesup26`) | **Shop box** | Main lobby, Currency Shop → Codes |
| `yay fishing` | **Chat, in-run** | During the fishing minigame, never the shop |
| A code from physical merchandise | **Merch box** | Buy Diamonds window → Codes → tick "Merch" |
| A code from the official web portal | **Web portal, then in-game** | Redeem on the site, enter the game within 24 h |

If you are not sure which kind you have: it is almost always the shop box. Chat codes and Merch codes are the exceptions, and both are flagged wherever you found the code.

## Path 1 — The Shop Box (Most Codes)

The redeem box is **inside the Currency Shop**, not in its own menu — which is exactly why so many players cannot find it. And it only exists in the **main lobby**: once a run has started, there is nothing to click.

1. Launch the game and **stay in the lobby**. Do not start a run.
2. Open the **Currency Shop**: click the Gems or Diamond button, or the diamonds icon at the bottom-left of the screen.
3. Click the **Codes** button in the **bottom-right** of that window.
4. Paste the code exactly as written — no extra spaces before or after.
5. Press **Submit**. The reward lands instantly.

Two things worth knowing before you type:

- **Copy and paste instead of typing.** Most sources and player reports say codes are case-sensitive (one tracker claims otherwise), and a trailing space pasted by accident causes the same failure. Pasting from the code list settles both at once.
- **There is no level requirement** and no group membership needed — the box works on a fresh account.

## Path 2 — The Chat-Only Code (`yay fishing`)

`yay fishing` **does not work in the shop box, ever.** It is a hidden in-run activation:

1. Start a session and upgrade the campfire to **Level 2**.
2. Get the **Old Rod** from the Fishing Shack.
3. Begin the fishing minigame.
4. Press **`/`** to open chat, type `yay fishing`, and press Enter.

The reward drops into the world — pick it up. It is one-time per account, and you will see it written as either 2 Diamonds or 2 Gems; they are the same currency (the full comparison is on [How to Get Diamonds Fast](/items/how-to-get-diamonds-fast)).

## Path 3 — Merch Codes (The Checkbox)

If you bought physical 99 Nights merchandise, its DLC code looks broken until you use the right box:

1. Open the **Buy Diamonds** window and click **Codes** in the bottom-right.
2. In the pop-up, **tick the "Merch" box** before submitting.

Missing that checkbox is the single most common reason a legitimate merch code appears to fail. See [Codes Not Working](/codes/codes-not-working) if it still rejects after ticking it.

## Path 4 — The Web Portal

Merch codes can also be redeemed through the official web portal — with one trap: **you must enter the game within 24 hours** of the web redemption, or the code expires and has to be re-entered. Redeem on the site right before you plan to play, not days ahead.

## How You Know It Worked

- The reward is added **instantly** — there is no pending or processing state.
- Every code is **one-time per account**. A second attempt on the same account returns "already redeemed", which is not a bug.
- If nothing happens and no message appears, you are almost certainly mid-run. The box does not exist outside the lobby.

## Common Mistakes, Compressed

- **Starting a run first.** The box is lobby-only.
- **Chat code into the shop box.** `yay fishing` will never work there.
- **Merch code without the checkbox.** Tick "Merch" or it fails.
- **Retyping by hand.** Paste it.
